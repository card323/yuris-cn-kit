《鏖呪ノ嶼》简体中文汉化补丁  说明
====================================================================

一、这是什么
--------------------------------------------------------------------
这不是"改好的游戏文件"，而是一个补丁器：它在你自己电脑上的游戏目录里，
按照译文表重新生成汉化包，再把游戏改到能显示简体中文的状态。

所以这个包里没有原版游戏文件，也没有打包好的汉化 update1.ypf。
它需要你自备一份正版本体（本补丁不提供、也不绕过任何授权校验）。


二、安装
--------------------------------------------------------------------
1. 把本压缩包完整解压到一个普通文件夹（不要在压缩包里直接运行）。
2. 关掉游戏（包括后台没退干净的进程）。
3. 双击  安装汉化.bat

   补丁器会自动找到游戏目录。如果找不到，把游戏文件夹直接拖到
   安装汉化.bat 上，或者在命令行里指定：
       安装汉化.bat "D:\...\鏖呪ノ嶼"
       （或 install_cn_patch.exe --game "D:\...\鏖呪ノ嶼"）

4. 整个安装约十几秒到一分钟（要重新编码并打包两万行文本）。
   出现"安装完成"后直接启动游戏即可。

安装过程会做四件事：
  [1/4] 从你自己那份 pac\bn.ypf 里解出原始引擎脚本
  [2/4] 把译文注入脚本，整体转成 CP936（GB2312），重新打包成 update1.ypf
  [3/4] 校验重建结果是否与本次发布逐字节一致（SHA-256）
  [4/4] 写入 update1.ypf（游戏根目录 + pac\）、修补 exe、安装字体


三、卸载
--------------------------------------------------------------------
双击  卸载汉化.bat  （或  install_cn_patch.exe --uninstall）

它会读取游戏目录下的 cn_patch_state.json，把这次安装改过的每一个文件
按备份还原回去，包括：
  - 还原 update1.ypf（如果原来就有）或删掉新写入的那两个
  - 还原 oujunoshima.exe（来自 oujunoshima.exe.orig 备份）
  - 注销并删除两个字体文件
  - 把 save\config.sd 改回来（见下面第六节）
卸载完成后游戏就回到原版状态。cn_patch_state.json 请勿手动删除，
卸载靠它；备份文件（*.pre-cn-patch、oujunoshima.exe.orig）也是。


四、它到底改了什么（可以逐条核对）
--------------------------------------------------------------------
1) 游戏目录下新增/替换两个数据包
       update1.ypf        （若原本存在，先备份为 update1.ypf.pre-cn-patch）
       pac\update1.ypf    （同上）
   内容 = 你自己 bn.ypf 里的引擎脚本 + 本补丁的译文，全部按 CP936 重编码。

2) oujunoshima.exe 改 3 处（先备份为 oujunoshima.exe.orig）
       - 建立字体时请求的字符集：0x80（CP932/日文）→ 0x86（GB2312/中文）
       - 三个字体名字面量：日文字体名 → Glow Sans SC / Microsoft YaHei / SimHei
       - 双字节前导字节表：按 CP936 的合法前导字节集重算（补充 A0 C7 C8 FD FE）
   仅这 3 处，共 52 字节。exe 的代码段、校验、存档格式都没动。

3) 字体（Windows 系统字体，不是游戏目录）
       生成并注册 Glow Sans SC、Glow Sans SC Bold 两个字体文件
       （由 OFL 授权的 Glow Sans SC Normal Light 改名+改行距而来，见 NOTICE.md §3）

4) save\config.sd 改名为 save\config.sd.pre-cn-patch
   游戏会把"设定"里选过的字体记在这个文件里，那个选择会盖过补丁；
   改名相当于让它恢复默认。副作用是你的其它设定（音量、文字速度等）
   也会回到默认值。若想保留设定，安装时用
       install_cn_patch.exe --keep-config
   卸载时这个文件会被改回来。


五、如果出问题
--------------------------------------------------------------------
* 报"游戏目录找不到" → 用拖拽或 --game 指定。
* 报"数据包不是已知的原版" → 你的 bn.ypf 与发行版不同（可能是别的版本
  或破解版）。确认自己备份了原版文件后，可以加 --force 继续。
* 报"重建结果与发布件不一致" → payload 里的译文表/工具被改动过，
  请重新下载压缩包。这一步是安全闸：宁可停下也不写出错的数据包。
* 启动后仍是日文 → 先确认游戏是不是走了别的 update*.ypf；
  再试 --keep-config 的反面：检查 save\config.sd 是否被游戏重新生成。
* 文字能显示但字形难看 → 字体的安装那一步失败了，安装日志在
  游戏目录的 cn_patch_install.log，重跑一次通常就好。
* 杀毒软件报毒 → 见第六节。

详细排查见 docs/TROUBLESHOOTING.md（补丁仓库里）。


六、杀毒软件 / 为什么用 Python 打包
--------------------------------------------------------------------
补丁器是一个用 PyInstaller 打包的 Python 程序（--onedir，不压缩壳、
不加壳），报毒通常是启发式误报。两种处理方式：
  1) 把 install_cn_patch 整个文件夹加进杀软白名单；
  2) 改用源码版：安装 Python 3.10+ 后双击  安装汉化-源码版.bat，
     它会 pip 安装依赖并直接跑 install_cn_patch.py（代码可读、可审）。
两条路跑的逻辑完全相同。
